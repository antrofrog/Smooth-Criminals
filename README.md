> The signal was always there.

ChudBot is an experimental personality-driven bot
built to observe, interpret, and react to internet culture.

## Features

- Personality-driven responses
- Contextual message classification
- Lightweight JavaScript engine
- Interactive terminal interface
- No API key required
- Automated tests

## Installation

    npm install
    npm start

## Testing

    npm test

## Project Structure

- src/bot.js — response engine
- src/index.js — interactive CLI
- tests/bot.test.js — tests

## Roadmap

- X mention integration
- AI language-model support
- Conversation memory
- Automated replies

## Status

Experimental. Not yet connected to X.
